01 · 판매 조건

선택값이 모두 있어야 다음으로

GS25 또는 CU 중 하나, 1+1 또는 2+1 중 하나를 고른 뒤 상품 등록으로 넘어갑니다.

01
선택 카드 우선일반 라디오보다 큰 카드로 선택 상태를 명확하게 보여줍니다.
02

운영자 흐름 · 상태 불변성

운영자는 신청을 확인하고, 상품마다 결과를 남긴다

연락 시작은 외부 연락을 대신하지 않고 상태만 기록합니다. 구매 또는 거절 처리된 상품은 다시 수정하거나 되돌리지 않습니다.

상태와 텍스트를 함께 사용
01 · 목록신청 목록

시점 → 조건 → 상품 수 → 상태 순서로 빠르게 봅니다.

02 · 상세신청 상세

연락처와 보관상품 이미지를 충분한 크기로 확인합니다.

03 · 연락연락중

`판매자에게 연락 시작`으로 외부 연락 시작을 기록합니다.

04 · 상품상품별 처리

각 StoredItem을 구매 또는 거절로 독립 처리합니다.

05 · 자동처리완료

모든 상품이 끝나면 별도 완료 버튼 없이 자동 전환합니다.
