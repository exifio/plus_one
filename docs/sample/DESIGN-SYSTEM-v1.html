06 · PRINCIPLES

최소 기준과 피해야 할 것

접근성과 서비스 신뢰를 해치지 않는 범위에서, 필요한 규칙만 유지합니다.

반응형 · 접근성

  • ✓
    360 / 768 / 1280px 확인모바일부터 데스크톱까지 자연스럽게 이어집니다.
  • ✓
    명확한 focus 상태키보드 사용자가 현재 위치를 확인할 수 있습니다.
  • ✓
    Label과 control 연결Placeholder를 Label 대신 사용하지 않습니다.
  • ✓
    색상 외의 상태 표현테두리, 아이콘, 문구를 함께 사용합니다.
  • ✓
    약 44px 이상의 클릭 영역주요 조작은 터치 환경에서도 안정적이어야 합니다.

피해야 할 것

  • ×
    AI 생성 대시보드풍 장식Gradient, glassmorphism, 과한 animation을 피합니다.
  • ×
    Primary 버튼 남용한 화면에서 가장 중요한 행동 하나를 분명하게 둡니다.
  • ×
    가짜 사회적 증거후기, 거래 건수, 긴급성 표현을 임의로 만들지 않습니다.
  • ×
    실험이라는 인상판매자에게 MVP나 테스트 페이지처럼 보이게 하지 않습니다.
  • ×
    검증되지 않은 확장다크모드나 대형 컴포넌트 라이브러리를 먼저 만들지 않습니다.
